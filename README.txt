INSIDE TRACK — ONE WEBSITE, THREE COLOUR THEMES

This is one unified website, not three separate copies.
Use the floating “Colour theme” selector at the bottom-right of any page:
- White Chocolate
- Dutch White
- Old Lace

Your selection is saved in this browser and follows you between the website pages.

Run:
1. Extract this folder.
2. Keep all files together.
3. Open index.html, or deploy the complete folder to your static hosting provider.

Checks performed:
- All supplied JavaScript files plus the theme-switcher.js pass Node syntax checks.
- Local HTML href/src references resolve to files in this folder.
- Theme selector and shared theme stylesheet/script are included on every HTML page.

Production limitation:
This is not certified as fully production-tested. Browser/device testing on your actual host,
HTTPS/domain configuration, Supabase setup, database/RLS/storage policies, and secure admin
authentication still require implementation and deployment testing. The supplied Admin
Dashboard currently uses localStorage and must not be considered secure multi-user access control.
